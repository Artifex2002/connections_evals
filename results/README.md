# Results

- `manifests/`: small, versioned provenance records; copy and fill `example.json` for each result.
- `tables/`: curated, small summary tables suitable for version control.
- `figures/`: curated figures selected for sharing or the paper; PNG/PDF files here are explicitly allowed by `.gitignore`.
- `generated/`: bulk local plot outputs; ignored by Git.

This repository does not yet contain the original experiment results. Empty curated directories indicate intended destinations, not recovered artifacts.
